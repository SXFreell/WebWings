# WebWings

基于 React、TypeScript、Vite 与 shadcn/ui 的 Manifest V3 浏览器扩展。默认提供本地收藏夹，也可选择连接自托管 WebWings 同步服务。

## 功能

- 一键读取并收藏当前标签页
- 多层嵌套目录
- 收藏与目录的新增、编辑、移动、删除
- 名称和网址搜索
- 默认、时间正倒序、标题正倒序排序，并自动记住选择
- IndexedDB 本地持久化
- 设置页导出全部收藏，并可选择目标目录合并导入
- 当前目录的独立导出与定向导入
- 导入时自动更新全部条目 ID 与父节点 ID

## 本地开发

```bash
pnpm install
pnpm dev
```

## 构建并安装到 Chrome

```bash
pnpm build
```

打开 `chrome://extensions`，启用“开发者模式”，点击“加载已解压的扩展程序”，选择本项目的 `dist` 目录。

## 验证

```bash
pnpm test
pnpm build
```

完整自动验证（包括协议、服务端和 OpenSpec）使用：

```bash
pnpm verify
```

## 云同步连接

在扩展设置中输入 Server URL 和 `srkey`，然后点击连接。扩展会先请求该精确 Origin 的 Chrome 运行时权限，再读取服务发现信息；服务身份、协议版本和最低客户端版本通过验证前，不会提交 `srkey`。

生产服务必须使用 HTTPS。仅 `localhost`、`127.0.0.1` 与 `[::1]` 可使用 HTTP；包含用户名、密码、查询参数或片段的地址会被拒绝。连接完成后扩展只保存规范化 URL、服务实例与 Key 标识、设备凭证、epoch 和游标，不会保存原始 `srkey`。

首次绑定会先下载 `webwings-sync-backup` ZIP，其中包含云端和本地数据及校验清单，但不含 Key 或设备凭证。若云端为空，备份完成后使用本地数据初始化；若云端已有数据，可选择“使用云端”“使用本地”或“合并”。关闭弹窗、下载失败或数据版本变化时，向导会保留本地数据并要求安全地恢复或重新开始。

轮换 Key 会立即使旧 Key、设备会话和实时连接失效。删除 Key 会先进入可恢复的待删除状态，保留期后才清理数据；恢复会生成新 Key，旧设备仍需重新绑定。管理员可管理 Key 的元数据，但不能读取其他 Key 的收藏内容。

同步中的临时网络错误不会阻止本地浏览和编辑；扩展会在后台重试并通过增量拉取收敛。Chrome 或设备关闭、休眠时不保证实时到达，重新启动、恢复网络或打开弹窗后会自动补拉。

服务端部署、反向代理、备份和管理员恢复请参阅 [server/README.md](server/README.md)。

### 双 Profile 手工验收

在发布前，用两个独立 Chrome Profile 加载同一份扩展，并让两者连接到同一测试 Key：

1. 在 Profile A 完成首次绑定，确认备份下载完成后选择策略；Profile B 使用同一 Key 完成绑定并确认其初始树一致。
2. 在 A 新建、编辑和移动收藏，确认 B 在保持 Chrome 打开时自动出现更新；再在 B 做反向修改，确认 A 收敛。
3. 让 B 离线，在 B 修改收藏后恢复网络，确认双方收敛且没有重复节点。
4. 使用管理员 Key 创建普通 Key、轮换它并删除/恢复它；确认旧设备会话被撤销、恢复后的新 Key 可重新绑定，且管理员界面不显示其他 Key 的收藏内容。

导出的 JSON 使用 `webwings-bookmarks` 格式与版本号。左下角“设置”页面用于导出全部数据或将文件导入到根目录及任意现有目录；进入真实目录后，右上角菜单可以只导出当前目录内容，或直接导入到当前目录。

导入采用合并模式，不会删除或覆盖现有收藏。系统会先校验项目类型、目录关联、循环嵌套、日期、重复 ID 和 URL 协议，然后为每个导入节点生成新 ID，并按照同一映射更新父节点 ID，因此同一文件可以安全地重复导入。
