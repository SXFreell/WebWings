## Why

当前收藏夹的目录操作菜单定位错误，数据管理入口也缺少独立页面；同时列表无法切换排序方式，导入导出只能整库覆盖，不能围绕目录安全地迁移数据。这些问题限制了收藏夹在目录较多、需要备份或跨环境整理数据时的可用性。

## What Changes

- 修复目录行“三个点”操作菜单的锚点与方向，使菜单显示在触发按钮下方，并保持在弹窗可视区域内。
- 将左下角“数据管理”入口替换为“设置”按钮；点击后右侧主内容区切换到设置页面，首期仅提供导入和导出功能。
- 为收藏列表增加默认排序、时间排序和标题排序；时间和标题排序均支持正序与倒序，排序选择在本地持久化。
- 设置页提供“导出全部”，并允许导入 JSON 时选择根目录或任意现有目录作为目标位置。
- 真实目录页面右上角提供上下文导入导出：导出当前目录内容，或导入到当前目录。
- **BREAKING**：将导入行为从覆盖整库改为合并导入；所有导入节点生成新 ID，并同步重映射内部父节点 ID，顶层导入节点连接到用户选择的目标目录。
- 当前目录导出生成自包含数据：包含目录内全部收藏和子目录，但不重复包含当前目录本身，导出数据中的顶层节点父 ID 归一化为空。

## Capabilities

### New Capabilities

- `bookmark-workspace-navigation`: 目录操作菜单定位、侧栏设置入口和右侧收藏/设置页面切换行为。
- `bookmark-sorting`: 收藏列表默认、时间和标题排序及排序偏好持久化。
- `bookmark-data-transfer`: 全量与目录级导出、目标目录导入、合并导入和 ID/父节点 ID 重映射。

### Modified Capabilities

无。当前项目尚无既有 OpenSpec capability。

## Impact

- 主要影响 `src/App.tsx` 中的侧栏、目录树、工具栏、收藏列表和导入导出交互。
- 需要新增设置页业务组件，并将当前单文件页面按工作区、设置和数据传输对话框拆分。
- 影响 `src/lib/bookmarks-db.ts` 的查询、范围导出与批量合并写入 API，以及 `src/types.ts` 的排序配置和可移植导出数据类型。
- 需要扩充 IndexedDB 数据层测试与界面交互测试；不新增浏览器权限，不改变 Manifest V3 配置。
