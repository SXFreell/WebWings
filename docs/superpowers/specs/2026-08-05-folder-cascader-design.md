# 目录级联选择器设计

## 目标

将现有的扁平目录下拉框统一替换为多列级联选择器，覆盖以下入口：

- 添加或编辑收藏时的“保存到”；
- 创建或编辑目录时的“上级目录”；
- 从设置页导入收藏时的“导入到”。

用户可以快速识别目录层级、进入任意深度，并直接选择任何一级目录，包括仍有子目录的父目录。

## 交互设计

触发器显示当前目录的完整路径，层级之间使用 ` / ` 分隔。收藏对话框的空值显示“未分类”，目录和导入对话框的空值显示“根目录”。

打开弹层后，每一级目录显示为独立列：

- 第一列显示根节点入口和全部顶级目录；
- 悬停带有子目录的条目时，在右侧打开其子目录列；
- 点击任意目录立即选中该目录并关闭弹层；
- 点击根节点入口会选择 `null` 并关闭弹层；
- 当前值显示勾选状态，当前路径保持展开；
- 带子目录的条目显示右箭头，表达可继续浏览；
- 弹层限制最大高度和可见宽度，内容过多时支持纵向和横向滚动。

键盘焦点、禁用状态、外部点击关闭和 Escape 关闭遵循现有 Radix 组件的行为。触发器保留清晰的焦点样式和当前路径文本。

## 组件边界

新增可复用的 `FolderCascader` 组件。组件负责：

- 将扁平的 `FolderNode[]` 转换为按父节点分组且稳定排序的级联列；
- 根据当前值计算完整路径和默认展开列；
- 管理悬停路径和弹层开关状态；
- 呈现根节点、选择状态、子级箭头及空列状态；
- 通过 `onValueChange(string | null)` 返回最终选择。

组件接口包含：

- `folders`：全部可用目录；
- `value`：当前目录 ID 或 `null`；
- `onValueChange`：选择回调；
- `rootLabel`：根节点显示文案；
- `placeholder`：无有效路径时的占位文案；
- `excludedIds`：不可显示的目录集合；
- `disabled`：禁用整个选择器。

目录树的纯数据计算放在 `bookmark-tree` 模块中，便于独立测试；展示和交互状态保留在组件内部。

## 三处接入

### 收藏对话框

用 `FolderCascader` 替换 Radix Select。`null` 对应“未分类”，保存数据结构不变。

### 目录对话框

用 `FolderCascader` 替换 Radix Select。`null` 对应“根目录”。编辑目录时继续排除自身和所有后代，避免形成循环父子关系。

### 导入对话框

当目标未锁定时使用 `FolderCascader`，`null` 对应“根目录”。当目标已锁定时保留现有只读路径展示，不提供弹层交互。

## 数据与异常处理

持久化模型、保存回调和 IndexedDB 行为不变。级联选择器只处理现有的目录 ID 与 `null`。

- 当前 ID 不存在或已被排除时，触发器回退到根节点文案；
- 孤立目录不会导致递归失败；
- 循环父子关系通过已访问 ID 集合截断，避免无限遍历；
- 空目录集合仍显示可选的根节点；
- 同级目录继续使用现有的 `order` 和中文标题排序规则。

## 测试与验收

采用测试驱动方式，先为纯数据行为添加失败测试，再实现最小逻辑：

- 根据当前值生成完整路径和初始级联列；
- 悬停父目录后生成正确的下一列；
- 任意父目录都可作为最终值；
- 排除目录时不会暴露其自身或后代；
- 无效 ID、空目录和异常层级安全回退；
- 三个对话框正确传递各自的根节点文案、当前值和排除集合。

完成后运行完整 Vitest 测试和 TypeScript/Vite 构建。人工验收三处入口的打开、悬停展开、父级选择、深层路径显示、根节点选择、编辑目录排除和导入锁定状态。

## 非目标

- 不修改目录数据模型或数据库结构；
- 不增加搜索、目录创建快捷入口或多选功能；
- 不改变导入、收藏或目录保存流程；
- 不重构侧边栏目录树。
