## Purpose

定义 WebWings 独立设置页在浏览器标签页中的视口占用、响应式尺寸和滚动行为，同时保持扩展 popup 原有的固定工作区体验。

## ADDED Requirements

### Requirement: 设置页必须使用浏览器可用视口
独立设置页 SHALL 使用浏览器标签页的完整可用宽度和至少完整视口高度，不得继承 popup 的固定宽高约束。

#### Scenario: 在浏览器标签页打开设置页
- **WHEN** 用户通过扩展设置入口打开独立设置页
- **THEN** 页面根区域占据标签页完整可用宽度和至少完整视口高度
- **AND** 页面不被限制为 popup 的固定尺寸

#### Scenario: 调整设置页窗口尺寸
- **WHEN** 用户改变浏览器窗口的宽度或高度
- **THEN** 设置页布局随可用视口重新排布
- **AND** 不出现由固定页面宽高造成的内容裁剪

### Requirement: 设置页全部内容必须可滚动访问
当设置内容高度超过可用视口时，系统 MUST 提供可用的纵向滚动，使用户能够访问首次绑定、Key 管理、数据管理和页脚中的全部内容。

#### Scenario: 设置内容超过视口高度
- **WHEN** 设置页内容总高度大于当前浏览器视口
- **THEN** 用户可以纵向滚动到页面最后一个设置项和页脚
- **AND** 页面级 `overflow` 规则不得阻止滚动

#### Scenario: 首次绑定向导展开
- **WHEN** 首次绑定向导显示备份说明、错误提示或策略选项并增加页面高度
- **THEN** 向导全部操作仍可通过滚动到达
- **AND** 向导内容不被外层容器裁剪

### Requirement: Popup 布局必须保持独立
扩展 popup SHALL 继续使用其既定固定工作区尺寸和内部滚动行为，设置页布局规则不得改变 popup 的可见尺寸或导航体验。

#### Scenario: 打开扩展 popup
- **WHEN** 用户点击浏览器工具栏中的 WebWings 图标
- **THEN** popup 保持 `760×580` 的工作区尺寸
- **AND** 收藏管理区域继续在该工作区内按既有方式显示和滚动
