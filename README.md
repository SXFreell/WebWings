# WebWings

基于 React、TypeScript、Vite 与 shadcn/ui 的 Manifest V3 浏览器扩展。当前提供本地收藏夹功能。

## 功能

- 一键读取并收藏当前标签页
- 多层嵌套目录
- 收藏与目录的新增、编辑、移动、删除
- 名称和网址搜索
- 默认、时间正倒序、标题正倒序排序，并自动记住选择
- IndexedDB 本地持久化
- 设置页导出全部收藏，并可选择目标目录合并导入
- 当前目录的独立导出与定向导入
- 导入时自动更新全部条目 ID 与父节点 ID

## 本地开发

```bash
pnpm install
pnpm dev
```

## 构建并安装到 Chrome

```bash
pnpm build
```

打开 `chrome://extensions`，启用“开发者模式”，点击“加载已解压的扩展程序”，选择本项目的 `dist` 目录。

## 验证

```bash
pnpm test
pnpm build
```

导出的 JSON 使用 `webwings-bookmarks` 格式与版本号。左下角“设置”页面用于导出全部数据或将文件导入到根目录及任意现有目录；进入真实目录后，右上角菜单可以只导出当前目录内容，或直接导入到当前目录。

导入采用合并模式，不会删除或覆盖现有收藏。系统会先校验项目类型、目录关联、循环嵌套、日期、重复 ID 和 URL 协议，然后为每个导入节点生成新 ID，并按照同一映射更新父节点 ID，因此同一文件可以安全地重复导入。
