## Purpose

定义收藏数据在整库或目录范围内安全导出、校验和合并导入的行为，使 JSON 备份可被放入任意目标目录且不会覆盖或破坏现有收藏。

## ADDED Requirements

### Requirement: 设置页可以导出全部收藏数据
系统 SHALL 从设置页将全部目录和收藏导出为一个符合 WebWings 格式的 JSON 文件，并保留完整目录层级和条目元数据。

#### Scenario: 导出全部
- **WHEN** 用户在设置页面点击“导出全部”
- **THEN** 系统下载包含数据库中全部目录和收藏的 JSON 文件
- **AND** 每个非顶层节点的父节点 ID 指向同一文件中的目录节点

#### Scenario: 空收藏夹导出全部
- **WHEN** 收藏夹为空且用户点击“导出全部”
- **THEN** 系统仍下载有效的 WebWings JSON 文件
- **AND** 文件中的节点集合为空

### Requirement: 目录页可以导出当前目录内容
系统 SHALL 在用户选中真实目录时提供“导出当前目录”，导出该目录内的直接收藏、子目录及所有后代节点，但不包含当前目录节点自身。

#### Scenario: 导出含子目录的当前目录
- **WHEN** 用户在真实目录页面的右上角菜单点击“导出当前目录”
- **THEN** 导出文件包含当前目录的全部直接内容和后代内容
- **AND** 当前目录的直接子节点在导出副本中的父节点 ID 为 null
- **AND** 后代节点继续指向导出文件中对应的父目录

#### Scenario: 非真实目录视图
- **WHEN** 用户位于“全部收藏”“未分类”或设置页面
- **THEN** 系统不提供“导出当前目录”操作

### Requirement: 设置页导入可以选择目标目录
系统 SHALL 在设置页导入 JSON 时允许用户从根目录和全部现有目录中选择一个目标位置，并将导入内容合并到该位置。

#### Scenario: 导入到根目录
- **WHEN** 用户选择根目录并提交有效的 WebWings JSON 文件
- **THEN** 导入文件中的顶层节点被添加到根目录
- **AND** 当前数据库中的现有节点保持不变

#### Scenario: 导入到选定目录
- **WHEN** 用户选择一个现有目录并提交有效的 WebWings JSON 文件
- **THEN** 导入文件中的顶层节点被添加为该目录的直接子节点
- **AND** 当前数据库中的现有节点保持不变

### Requirement: 目录页导入默认使用当前目录
系统 SHALL 在真实目录页面的右上角菜单提供“导入到当前目录”，且不得再次要求用户选择目标目录。

#### Scenario: 导入到当前目录
- **WHEN** 用户位于真实目录并通过右上角菜单选择“导入到当前目录”后提交有效文件
- **THEN** 导入文件中的顶层节点被添加为当前目录的直接子节点

### Requirement: 导入必须重映射全部节点标识
系统 MUST 为每个导入目录和收藏生成与当前数据库及同批其他节点均不重复的新 ID，并按同一映射更新其内部父节点 ID。

#### Scenario: 重映射嵌套结构
- **WHEN** 导入文件包含多层目录和收藏
- **THEN** 每个导入节点的 ID 都不同于文件中的原 ID
- **AND** 每个非顶层导入节点的父节点 ID 指向其导入后父目录的新 ID
- **AND** 每个顶层导入节点的父节点 ID 指向所选目标目录或根目录

#### Scenario: 重复导入同一文件
- **WHEN** 用户将同一文件连续导入两次
- **THEN** 两次导入都成功创建独立节点树
- **AND** 两批节点之间不存在 ID 冲突

### Requirement: 导入必须先校验并原子写入
系统 MUST 在写入前校验文件格式、节点类型、URL、父节点关系、重复 ID 和循环目录；整批导入 SHALL 在单个事务中完成。

#### Scenario: 文件校验失败
- **WHEN** 用户提交格式无效或包含不安全链接、缺失父目录、重复 ID 或循环目录的文件
- **THEN** 系统显示可理解的错误信息
- **AND** 数据库不得写入该文件中的任何节点

#### Scenario: 写入事务失败
- **WHEN** 合并导入过程中数据库事务失败
- **THEN** 整批导入回滚
- **AND** 数据库保持导入前状态

### Requirement: 导入保留条目内容和时间元数据
系统 SHALL 在更换 ID 和父节点 ID 之外保留导入节点的类型、标题、URL、图标、创建时间和更新时间，并为导入的顶层节点分配目标目录中连续的新顺序值。

#### Scenario: 保留可排序时间
- **WHEN** 用户导入包含历史创建时间的收藏
- **THEN** 该收藏继续使用文件中的创建时间参与时间排序

#### Scenario: 加入已有目录
- **WHEN** 目标目录已有节点且用户执行导入
- **THEN** 导入的顶层节点获得大于目标目录现有最大顺序值的连续顺序值
- **AND** 导入树内部的相对顺序保持不变
